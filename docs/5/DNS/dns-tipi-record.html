Sistemi e Reti · protocollo DNS

I recordDNS

Il DNS non conserva solo indirizzi IP. Ogni informazione è un record, e il suo tipo dice di che informazione si tratta.

Dove si trova il tipo

www.agnelli.it.3600INA46.105.204.27

Cambiando il tipo, cambia il significato del valore: un indirizzo, un altro nome, un server di posta…

Provalo dal terminale

# indirizzo IPv4
dig www.agnelli.it A
# server che ricevono la posta
dig agnelli.it MX
# server DNS del dominio
dig agnelli.it NS
# dall’IP al nome
dig -x 46.105.204.27

Che tipo di informazione?

nomi e indirizziservizigestione della zona
A

Indirizzo IPv4

Collega un nome a un indirizzo IPv4. È il record più usato: serve al browser per raggiungere un sito.

«Che IP ha www.agnelli.it?»
www.agnelli.it. IN A 46.105.204.27reale
AAAA

Indirizzo IPv6

Come A, ma per gli indirizzi IPv6, più lunghi e scritti in esadecimale.

«Che indirizzo IPv6 ha questo nome?»
www.agnelli.it. IN AAAA 2001:db8::10esempio
CNAME

Alias

Dice che un nome è un soprannome di un altro nome. Il resolver riparte cercando il nome vero.

«Questo nome è un alias di quale altro?»
sito.agnelli.it. IN CNAME www.agnelli.it.esempio
PTR

Ricerca inversa

Il contrario di A: dato un indirizzo IP, restituisce il nome. L’IP si scrive al contrario sotto il dominio speciale in-addr.arpa.

«A chi appartiene questo IP?»
27.204.105.46.in-addr.arpa. IN PTR server.esempio.it.esempio
MX

Posta elettronica

Indica quale server riceve le email per il dominio. Il numero è la priorità: si prova prima il più basso.

«A chi consegno le email per @agnelli.it?»
agnelli.it. IN MX 10 mail.agnelli.it.esempio
TXT

Testo

Testo libero associato a un nome. Si usa ad esempio per dimostrare a un servizio esterno che il dominio è proprio.

«Che informazioni aggiuntive ci sono?»
agnelli.it. IN TXT "verifica=abc123"esempio
NS

Server della zona

Elenca i server autoritativi del dominio. È il record dei rimandi che abbiamo visto con dig +trace.

«Chi conosce i nomi di agnelli.it?»
agnelli.it. IN NS ns113.ovh.net.reale
SOA

Inizio della zona

Uno solo per zona. Contiene il server primario, l’email del responsabile, il serial (il numero di versione della zona) e i tempi di aggiornamento.

«Chi gestisce la zona, e che versione è?»
agnelli.it. IN SOA ns113.ovh.net. … 2026102201 …esempio

«reale» = valore letto con dig su agnelli.it. «esempio» = valore illustrativo, da verificare con i comandi a sinistra.
